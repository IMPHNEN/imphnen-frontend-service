## Selamat Datang di ImphnenOS!

ImphnenOS adalah distribusi Linux yang dibangun di atas fondasi **Arch Linux**, dirancang secara khusus untuk memenuhi kebutuhan *programmer* dan *developer*. 

Berbeda dengan distribusi Linux lainnya yang bersifat *general-purpose*, ImphnenOS hadir dengan opini yang kuat (opinionated) mengenai bagaimana sebuah environment development seharusnya disiapkan. Kami sudah mengkonfigurasi terminal, editor, dan tools lainnya agar kamu bisa langsung mulai ngoding dalam hitungan menit setelah instalasi.

### Kenapa Memilih ImphnenOS?

1. **Pre-configured Environment**: Tidak perlu menghabiskan waktu berjam-jam untuk setup dotfiles. ZSH, Neovim, dan VS Code sudah terkonfigurasi dengan baik.
2. **Performa Tinggi**: Dibangun menggunakan Arch Linux sebagai basis, menjamin OS yang ringan tanpa *bloatware*.
3. **Rolling Release**: Selalu mendapatkan software versi terbaru. Sangat penting bagi developer yang selalu menggunakan fitur terbaru dari bahasa pemrograman.
4. **Dukungan Komunitas**: Didukung oleh komunitas IMPHNEN dengan ratusan ribu member yang siap membantu.

### Apa yang Ada di Dalamnya?

ImphnenOS tidak menggunakan Desktop Environment (DE), melainkan menggunakan Window Manager **mango** secara default untuk memaksimalkan performa dan produktivitas:

* **Window Manager**: mango
* **Terminal**: Alacritty + Zsh (Oh My Zsh)
* **Package Manager**: Pacman + Yay (AUR Helper)
* **Editor/IDE**: VS Code (OSS), Neovim
* **Tools Dasar**: Git, curl, wget, htop, neofetch
* **Dev Environments**: Node.js (via nvm), Python, Docker

### Mulai Darimana?

Jika ini adalah pertama kalinya kamu menggunakan ImphnenOS, kami merekomendasikan untuk membaca dokumen berikut secara berurutan:

1. Periksa [Persyaratan Sistem](/wiki/system-requirements) sebelum menginstal.
2. Ikuti [Panduan Instalasi](/wiki/installation-guide) untuk menginstal sistem operasi.
3. Setelah instalasi selesai, baca panduan [Setelah Instalasi](/wiki/post-installation) untuk beberapa konfigurasi awal.
4. Pelajari cara menginstal aplikasi di [Manajemen Paket](/wiki/package-management).
